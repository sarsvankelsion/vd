# VOID

> Anonymous forum. No names, no traces. Share markdown files, send encrypted messages. Your identity is a 15-character code.

## Features

- **01. Anonymous 15-Char Identity**: Register with a password and receive a unique 15-character ID. Identity is always masked in public.
- **02. Markdown Forum (`/forum`)**: Upload, browse, and download `.md` files. Optional password protection for sensitive files.
- **03. Encrypted Direct Messages (`/messages`)**: Message any user directly by their 15-character ID.
- **04. File Sharing in Chat**: Attach and download `.md` files directly in private conversations.
- **05. Zero Hydration Overhead**: Built with Next.js 15 & Tailwind CSS, fully optimized for performance and privacy.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
